# wishlist-php

Публичный сервис списков желаний на PHP + MySQL (PDO). Пользователи создают списки подарков к праздникам, другие могут их смотреть, добавлять в избранное или копировать понравившееся себе.

## Возможности

- Публичная лента всех списков с поиском и фильтрами (праздник, статус, тип желания).
- Регистрация/вход.
- Создание желания: название, описание, ссылка, цена, фото (тип файла проверяется по содержимому), статус, тип (себе/в подарок/универсальное).
- Карточка желания - публичная: доступна без входа, как и вся лента. Вход нужен только для действий - добавить к себе, редактировать, удалить.
- Копирование чужого желания в свой список одним кликом.
- Избранное (отмечается сердечком).
- Личный кабинет: свои списки по категориям + избранное.

## Технологии

- PHP (без фреймворка), PDO + MySQL

## Настройка

1. Скопируйте [config.example.php](config.example.php) в `config.php` и впишите свои данные подключения к MySQL. `config.php` в `.gitignore` - пароль не попадёт в репозиторий.
2. Выполните [createdb.sql](createdb.sql) в MySQL - создаст базу `wishlist_db` и таблицы.
3. Откройте `index.php` - каталог готов к работе.

## Структура

```
index.php              публичная лента всех списков
config.example.php     шаблон конфига подключения к БД (config.php не публикуется)
createdb.sql            схема БД
includes/db.php         подключение к БД
includes/auth.php       require для страниц, доступных только залогиненным
pages/login.php, register.php, logout.php
pages/create_wishlist.php  создание праздника + желания
pages/item_detail.php      карточка желания (публичная) + добавить себе/редактировать/удалить
pages/profile.php          личный кабинет
pages/view_wishlist.php    более ранняя версия просмотра списка, сейчас никуда не ведёт
uploads/                   загруженные фото (создаётся автоматически, не в репозитории)
```
